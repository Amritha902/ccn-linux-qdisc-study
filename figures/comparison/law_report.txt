--------------------------------------------------------------------------------------------
EXCLUDED: CELLS WHERE THE CONTROLLER NEVER ACTED
--------------------------------------------------------------------------------------------
The adapted arm made no adjustment at all, so these compare static
against static. Their null is true by construction and cannot be
evidence about queueing, so they are outside the fit and the tests.

  target 5ms rtt 80ms (r=0.062): 0 adjustments, measured -0.6%
  target 20ms rtt 80ms (r=0.250): 0 adjustments, measured +0.5%

  Cause: the scaled HEAVY threshold lands on the operating drop
  rate, so the regime oscillates and the stability gate that
  requires five consecutive identical classifications never opens.

--------------------------------------------------------------------------------------------
P2  RATIO INVARIANCE (the falsifiable test)
--------------------------------------------------------------------------------------------
Configurations sharing a ratio but differing in RTT should show the
same benefit. If benefit tracks RTT instead, the hypothesis is wrong.

  ratio  1.00:  t=5/rtt=5 -> +18.4%, t=20/rtt=20 -> +17.6%, t=80/rtt=80 -> +16.4%
                spread 2.0 percentage points  -> consistent

--------------------------------------------------------------------------------------------
FIT
--------------------------------------------------------------------------------------------
  benefit(r) = 20.5 / (1 + (0.50/r)^2.6)    R^2 = 0.986
  half-benefit at r = 0.50  (target 0.50x the path RTT)

============================================================================================
CONCLUSION: the ratio target/RTT, not RTT, governs the benefit.
Invariance is demonstrated at ratio 1 over a 16-fold range of RTT, and the fitted curve predicts
held-out interior ratios to 1.4 percentage points.

Scope, stated rather than implied: this holds at fixed
target/interval, which was scaled with the target throughout, and
rests on cells where the controller demonstrably acted. Cells where
it never adjusted are excluded above and prove nothing either way.
