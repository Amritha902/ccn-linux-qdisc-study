\title{\vspace{-1cm}Runtime parameter adaptation for a flow-queueing active
queue discipline: a controlled evaluation on stock Linux}
\author{Amritha S \and Yugeshwaran P \and Deepti Annuncia}
\date{Vellore Institute of Technology, Chennai}

\twocolumn[\maketitle
\begin{abstract}\noindent
The default Linux queue discipline, \texttt{fq\_codel}, exposes four parameters
fixed at configuration time. Runtime adaptation of such parameters has been
proposed repeatedly, but never evaluated under conditions that separate a
controller's computational cost from the effect of its decisions. We implement
a controller that adapts all four parameters using an additive-increase
multiplicative-decrease policy informed by eBPF flow telemetry, and evaluate it
on an unmodified kernel against eight alternative queue disciplines under an
identical bottleneck, with three repetitions per condition and a
sham-controller condition that applies no change. Flow queueing with a delay
target reduces 95th-percentile latency by 99.0 per cent relative to an
unmanaged queue at indistinguishable goodput. Adapting that discipline's
parameters reduces mean queue occupancy by 9.6 per cent under a steady load and
produces no improvement under a load whose flow count varies, while an existing
queue discipline requiring no controller outperforms the adapted system by a
larger margin than the adaptation achieves.
\end{abstract}
